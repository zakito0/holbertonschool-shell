# Shell, init files, variables and expansions

This project covers shell initialization files, local and global (environment) variables, aliases, shell arithmetic, and expansions in Bash on Ubuntu 20.04 LTS.

## Scripts Description

| File | Description |
| --- | --- |
| [0-alias](./0-alias) | Creates an alias `ls` with the value `rm *`. |
| [1-hello_you](./1-hello_you) | Prints `hello user`, where `user` is the current Linux user. |
| [2-path](./2-path) | Adds `/action` to the `PATH`. |
| [3-paths](./3-paths) | Counts the number of directories in the `PATH`. |
| [4-global_variables](./4-global_variables) | Lists environment variables. |
| [5-local_variables](./5-local_variables) | Lists local variables, environment variables, and shell functions. |
| [6-create_local_variable](./6-create_local_variable) | Creates a new local variable named `BEST` with value `School`. |
| [7-create_global_variable](./7-create_global_variable) | Creates a new global variable named `BEST` with value `School`. |
| [8-true_knowledge](./8-true_knowledge) | Prints the result of the addition of 128 with `TRUEKNOWLEDGE`. |
| [9-divide_and_rule](./9-divide_and_rule) | Prints the result of `POWER` divided by `DIVIDE`. |
| [10-love_exponent_breath](./10-love_exponent_breath) | Displays the result of `BREATH` to the power of `LOVE`. |
